# Task 3 - Interactive Dashboard Using Power BI

## Overview

This project focuses on designing an interactive Power BI dashboard using the Global Happiness Report dataset. The dashboard provides meaningful insights into happiness scores and the factors that influence happiness across different countries and regions through interactive visualizations.

## Objectives

- Import and transform the dataset in Power BI
- Clean and prepare the data
- Create calculated columns and measures using DAX
- Build interactive visualizations
- Analyze key happiness indicators
- Develop an interactive dashboard for better decision-making

## Tools & Technologies

- Power BI
- DAX (Data Analysis Expressions)
- Microsoft Excel

## Dataset

**Global Happiness Report Dataset**

## Dashboard Features

- KPI cards for key metrics
- Region wise Happiness Trend
- Country-wise life expectancy range
- Economy Vs Happiness analysis
- Regional Analysis
- Average freedom by region
- Happiness level
- Dynamic charts and visualizations

## Key Insights

- Compared happiness scores across different regions.
- Identified the happiest countries.
- Analyzed the impact of GDP, health, freedom, trust, and generosity on happiness.
- Explored regional differences using interactive visuals.
- Built a user-friendly dashboard for effective data exploration.

## Project Outcome

An interactive Power BI dashboard that transforms raw happiness data into clear visual insights, helping users understand the factors influencing happiness across countries and regions.
